How the catalog is collected

Every record describes a concrete verification technique found in repository source or configuration. Its evidence is tied to the exact commit that was inspected.

What counts as evidence

A workflow invocation, a configured check or an implementation can establish a method. Records name the method and tool, preserve commands where found, and link the relevant source lines. Environment, working directory and conditions are retained with the evidence that they apply to.

A package name, a documentation mention or an instruction to use a technique is insufficient on its own. The original review-discussion instructions are available in the legacy collection; they are not counted as verification evidence.

Evidence states

StateWhat it establishes
Configured in CIA CI definition invokes the check. Event and job conditions may restrict its execution.
Configured locallyA command or configuration enables the check. CI invocation was not established.
Implementation presentSource code implements the check. Its invocation was not established.

These states describe the inspected source. They do not establish that a run succeeded, that a job runs on every change, or that the repository requires it before merging. A bounded check retains its configured bounds; it does not become a claim of exhaustive correctness.

Scope and freshness

The collector reads a repository tree and a bounded selection of candidate files. Detection covers supported methods and tools. Each source scan publishes the number of files considered, fetched and skipped, whether the tree was complete, and known limitations. Missing evidence may reflect those limits.

“Inspected” is the time of the scan. Source links use a full commit identifier so that later changes to a default branch do not change the evidence behind a record. A newer scan replaces that repository's snapshot.

Reproducible records

The source manifests are in _verification/. The build validates the record structure and pinned evidence URLs, then derives this catalog, detail pages and raw JSON and Markdown files. The website build does not run commands from inspected repositories.

Use the source coverage page to inspect a complete scan and the API to retrieve records programmatically.

Corrections

Report an incorrect detection or suggest a repository. Include the affected record and source evidence so the next scan can be checked against it.
