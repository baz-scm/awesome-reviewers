# The corpus, as JSON (versioned)
#   https://awesomereviewers.com/v1/index.json             every instruction, with markdown and JSON URLs
#   https://awesomereviewers.com/v1/domains.json           every domain, with counts and bundle URLs
#   https://awesomereviewers.com/v1/facets.json            every topic, language and repository
#   https://awesomereviewers.com/v1/sources.json           every source repository
#   https://awesomereviewers.com/v1/instructions/<slug>.json  one instruction, body included
#   https://awesomereviewers.com/v1/errors/index.json      every problem type
#   https://awesomereviewers.com/v1/errors/<code>.json     one problem type

# The corpus, as markdown and plain JSON
#   https://awesomereviewers.com/raw/index.json            every instruction, with raw URLs
#   https://awesomereviewers.com/raw/<slug>.md             one instruction as markdown
#   https://awesomereviewers.com/raw/bundles/<domain>.md   one domain as markdown
#   https://awesomereviewers.com/<slug>.json               the review discussions behind one instruction
#   https://awesomereviewers.com/assets/data/search.json   compact search index
#   https://awesomereviewers.com/404.md                    what to read after a bad guess
